# Hi, I’m Júnio 👋

**Software Engineer | Backend, APIs & Distributed Systems**

I’m a software engineer based in Brazil with **7+ years of experience** in web development, especially backend systems, ERP platforms, financial integrations, microservices, and APIs.

My core stack includes **PHP, Laravel, REST APIs, RabbitMQ, Redis, Docker, and SQL/NoSQL databases**. I work with asynchronous processing, maintainability, automated testing, and performance optimization.

Beyond my professional backend work, I build portfolio projects with **Rust, Go, Java, Python, and Ruby**, exploring reliability, distributed systems, and AI-assisted developer tooling.

## 📈 Professional Impact

Selected outcomes from my work at **Ambra**:

- **97% reduction** in a microservice’s processing time.
- **85% improvement** in dashboard rendering performance through SQL query optimization.
- **90% test coverage** achieved through expanded automated testing.
- Built a reusable **PHP Pix integration with Banco do Brasil** and worked on recurring billing refactoring, RabbitMQ-based asynchronous flows, Docker, and Azure Pipelines.

## 🚀 Featured Projects

### [Reliable Event Relay](https://github.com/juniocr26/rust-event-relay)

A completed distributed event-delivery project in Rust. Implements a transactional outbox, confirmed RabbitMQ publishing, lease-based delivery ownership, scheduled retries, idempotent consumption, quarantine, replay with audit records, recovery, readiness checks, and delivery metrics.

**Tech:** Rust · Tokio · Axum · SQLx · PostgreSQL · RabbitMQ · Docker

### [Engineering Library](https://github.com/juniocr26/engineering-library)

Local-first engineering knowledge and AI-assisted technical documentation platform. Includes a bilingual catalog, source-grounded documentation generation, local LLM inference, incremental updates, recovery, annotations, and evidence-based evaluations. The application is implemented; agent quality and coverage are under ongoing evaluation. Uses local inference, not model-weight fine-tuning.

**Tech:** Ruby on Rails · Next.js · TypeScript · PostgreSQL · Docker · Ollama · Python

### [Payment Reconciliation Lab](https://github.com/juniocr26/payment-reconciliation-lab)

Backend portfolio project under development, focused on comparing local payment records with Stripe test payments, explaining discrepancies, and recording auditable reconciliation runs. The reconciliation workflow is not yet complete.

**Tech:** Java · Spring Boot · Angular · PostgreSQL · Stripe · Docker

### VivaBem

Independent psychological care platform under active development. The ecosystem includes scheduling, Stripe Connect and Mercado Pago integrations, notifications, real-time communication, and internal infrastructure/observability tools. Includes a PWA and an Android TWA wrapper. **Private repository; high-level description only.**

**Tech:** PHP · Laravel · Node.js · RabbitMQ · Redis · MySQL · MongoDB · Docker · PWA

### [URL Shortener](https://github.com/juniocr26/url-shortener)

Completed URL-shortening API with authenticated creation, public redirects, atomic Redis ID allocation, Base62 encoding, Cassandra persistence, validation, and automated tests.

**Tech:** Python · FastAPI · Redis · Cassandra · Docker

### [ENV Auditor](https://github.com/juniocr26/env-auditor)

Completed dependency-free CLI for auditing and synchronizing environment-file keys against reference examples, with dry-run, private backups, atomic replacement, and safety checks. Does not claim secret detection.

**Tech:** Python · CLI · unittest

### [Go Image Optimizer](https://github.com/juniocr26/go-image-optimizer)

Completed image optimization app with a Go HTTP backend and Next.js UI. Supports compression, resizing, format conversion, EXIF orientation handling, upload limits, and automated tests.

**Tech:** Go · Next.js · React · WebP · AVIF · Docker
