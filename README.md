# Hi, I'm Júnio 👋

![Software Engineer — Backend, APIs & Distributed Systems](https://readme-typing-svg.demolab.com?font=Fira+Code&weight=600&size=24&duration=3000&pause=1500&color=2F81F7&vCenter=true&width=620&height=50&lines=Software+Engineer;Backend%2C+APIs+%26+Distributed+Systems)

I'm a Full Stack Software Engineer based in Brazil, with 7+ years of experience in web development and a strong focus on backend engineering.

I build web applications, APIs, integrations, and asynchronous systems, primarily with PHP and Laravel. My professional experience includes REST APIs, RabbitMQ, Redis, Docker, payment integrations, background processing, real-time communication, and database performance optimization.

On the frontend, I've worked with Angular, Vue.js, Alpine.js, Tailwind CSS, and JavaScript. My mobile experience includes Ionic and Angular applications, iOS build and publishing workflows with Xcode, and an Android Trusted Web Activity (TWA) wrapper for the VivaBem PWA, built with Bubblewrap and Docker.

My portfolio projects give me hands-on experience with Java and Spring Boot, Go, Python, FastAPI, Next.js, React, and distributed persistence. I am currently building Multi Store Commerce with a Spring Boot modular monolith, Angular, and PostgreSQL.

## 🚀 Featured Projects

### [Multi Store Commerce](https://github.com/juniocr26/multi-store-commerce)

A full-stack portfolio project in development for a fictional bakery network. The implemented foundation includes an active-store directory, a Spring Boot modular monolith, an Angular interface with loading, empty, error, and retry states, and PostgreSQL persistence with Flyway migrations.

Includes API tests, integration tests against real PostgreSQL with Testcontainers, Angular tests with Vitest and jsdom, local OpenAPI documentation, and a Docker Compose development environment. Catalog, checkout, and order management are planned for later increments.

**Tech:** Java • Spring Boot • Spring Security • Spring Data JPA • Hibernate • Angular • TypeScript • RxJS • PostgreSQL • Flyway • Maven • JUnit • Mockito • Testcontainers • Vitest • jsdom • Docker

### VivaBem

An independent psychological care platform currently in development, built as a PWA. It connects Laravel applications and supporting services through REST APIs and asynchronous messaging, with appointment scheduling, payment integrations, notifications, and real-time updates. The Android wrapper uses Trusted Web Activity, with a containerized Bubblewrap/Gradle build workflow and Digital Asset Links verification.

**Tech:** PHP • Laravel • Alpine.js • Tailwind CSS • RabbitMQ • Redis • MySQL • MongoDB • Stripe Connect • WebSockets • Docker • PWA • TWA • Bubblewrap

### [URL Shortener](https://github.com/juniocr26/url-shortener)

A backend and system design project exploring URL shortening with atomic ID generation in Redis, Base62 encoding, reversible code obfuscation, and persistence in a local three-node Cassandra cluster.

**Tech:** Python • FastAPI • Redis • Cassandra • Docker • Pytest

### [ENV Auditor](https://github.com/juniocr26/env-auditor)

A dependency-free Python CLI for auditing and synchronizing environment files, identifying potentially unused variables, and flagging possible secrets in `.env.example`. Includes dry-run and audit-only modes, backups, and safeguards for variables used outside the scanned code.

**Tech:** Python • CLI • Static Analysis • Developer Tooling

### [Go Image Optimizer](https://github.com/juniocr26/go-image-optimizer)

An image processing application for compression, resizing, and format conversion, built to explore Go through a practical backend use case. Includes a Next.js interface, byte-based format detection, processing limits, and server-generated previews for supported images the browser cannot display.

**Tech:** Go • Next.js • React • TypeScript • Tailwind CSS • Docker
