# Olá, sou Júnio 👋

**Engenheiro de Software | Backend, APIs e Sistemas Distribuídos**

Sou engenheiro de software no Brasil com **mais de 7 anos de experiência** em desenvolvimento web, especialmente sistemas backend, plataformas ERP, integrações financeiras, microsserviços e APIs.

Minha stack principal inclui **PHP, Laravel, APIs REST, RabbitMQ, Redis, Docker e bancos SQL/NoSQL**. Trabalho com processamento assíncrono, manutenibilidade, testes automatizados e otimização de desempenho.

Além da atuação profissional em backend, desenvolvo projetos com **Rust, Go, Java, Python e Ruby**, explorando confiabilidade, sistemas distribuídos e ferramentas de desenvolvimento assistidas por IA.

## 📈 Resultados Profissionais

Resultados selecionados da minha atuação na **Ambra**:

- **97% de redução** no tempo de processamento de um microsserviço.
- **85% de melhoria** no desempenho de renderização de dashboards por meio da otimização de consultas SQL.
- **90% de cobertura de testes** alcançada com ampliação dos testes automatizados.
- Desenvolvi uma integração **Pix com Banco do Brasil** em biblioteca PHP reutilizável e atuei na refatoração de cobrança recorrente, fluxos assíncronos com RabbitMQ, Docker e Azure Pipelines.

## 🚀 Projetos em Destaque

### [Reliable Event Relay](https://github.com/juniocr26/rust-event-relay)

Projeto concluído de entrega confiável de eventos distribuídos em Rust. Implementa outbox transacional, publicação confirmada no RabbitMQ, controle de entrega por leases, retentativas, consumo idempotente, quarentena, reprocessamento auditável, recuperação, verificações de prontidão e métricas.

**Tecnologias:** Rust · Tokio · Axum · SQLx · PostgreSQL · RabbitMQ · Docker

### [Engineering Library](https://github.com/juniocr26/engineering-library)

Plataforma local-first de conhecimento de engenharia e documentação técnica assistida por IA. Inclui catálogo bilíngue, geração fundamentada no código-fonte, inferência local com LLM, atualizações incrementais, recuperação, anotações e avaliações baseadas em evidências. A aplicação está implementada; a qualidade e a cobertura do agente seguem em avaliação. Usa inferência local, não fine-tuning de pesos.

**Tecnologias:** Ruby on Rails · Next.js · TypeScript · PostgreSQL · Docker · Ollama · Python

### [Payment Reconciliation Lab](https://github.com/juniocr26/payment-reconciliation-lab)

Projeto de portfólio backend em desenvolvimento, voltado à comparação de registros locais de pagamento com pagamentos de teste do Stripe, identificação de divergências e histórico auditável de conciliações. O fluxo de conciliação ainda não está concluído.

**Tecnologias:** Java · Spring Boot · Angular · PostgreSQL · Stripe · Docker

### VivaBem

Plataforma independente de atendimento psicológico em desenvolvimento ativo. O ecossistema inclui agendamentos, integrações com Stripe Connect e Mercado Pago, notificações, comunicação em tempo real e ferramentas internas de infraestrutura e observabilidade. Inclui PWA e aplicativo Android via TWA. **Repositório privado; descrição em alto nível.**

**Tecnologias:** PHP · Laravel · Node.js · RabbitMQ · Redis · MySQL · MongoDB · Docker · PWA

### [URL Shortener](https://github.com/juniocr26/url-shortener)

API de encurtamento de URLs concluída, com criação autenticada, redirecionamentos públicos, alocação atômica de IDs no Redis, codificação Base62, persistência no Cassandra, validação e testes automatizados.

**Tecnologias:** Python · FastAPI · Redis · Cassandra · Docker

### [ENV Auditor](https://github.com/juniocr26/env-auditor)

CLI concluída e sem dependências externas para auditoria e sincronização de chaves de arquivos de ambiente com exemplos de referência, incluindo simulação, backups privados, substituição atômica e verificações de segurança. Não realiza detecção de segredos.

**Tecnologias:** Python · CLI · unittest

### [Go Image Optimizer](https://github.com/juniocr26/go-image-optimizer)

Aplicação concluída de otimização de imagens, com backend HTTP em Go e interface Next.js. Suporta compressão, redimensionamento, conversão de formatos, tratamento de orientação EXIF, limites de upload e testes automatizados.

**Tecnologias:** Go · Next.js · React · WebP · AVIF · Docker
