# Olá, eu sou Júnio 👋

**Engenheiro de Software | Engenharia Backend | Sistemas Distribuídos**

Sou engenheiro de software brasileiro, com mais de sete anos de experiência no desenvolvimento de aplicações web, APIs, integrações e sistemas backend. Meu foco está em arquitetura de software, processamento assíncrono, desempenho, confiabilidade e facilidade de manutenção.

Trabalho principalmente com PHP e Laravel, bancos de dados relacionais e NoSQL, mensageria e Docker. Também tenho experiência Full Stack com frameworks JavaScript e fluxos de desenvolvimento e publicação de aplicações web e mobile. Procuro entender o problema, avaliar alternativas e construir soluções que possam ser testadas, operadas e evoluídas.

Em projetos independentes, continuo aprofundando meus conhecimentos em Java, Rust, Go, Python, Ruby e desenvolvimento assistido por IA local. Este perfil reúne o que venho construindo, as decisões técnicas envolvidas e os temas que sigo estudando.

## 🚀 Projetos em destaque

### [Reliable Event Relay](https://github.com/juniocr26/rust-event-relay)

Projeto concluído em Rust voltado à entrega confiável de eventos entre PostgreSQL e RabbitMQ. Combina outbox transacional, confirmação de publicação, controle de posse da entrega por leases e tokens, retentativas com backoff e jitter e reprocessamento auditável. O consumidor aplica efeitos transacionais idempotentes; o sistema também contempla quarentena, admissão limitada, recuperação, verificações de prontidão e métricas de entrega.

**Tecnologias:** Rust · Tokio · Axum · SQLx · PostgreSQL · RabbitMQ · Lapin · Docker

### [Engineering Library](https://github.com/juniocr26/engineering-library)

Plataforma local-first para leitura técnica, organização de conhecimento de engenharia e documentação assistida por IA. Reúne leitor web, catálogo bilíngue, navegação pelo código-fonte, anotações e favoritos a um fluxo de documentação com modelos locais via Ollama. A geração utiliza contexto selecionado do código e referências às fontes; o fluxo acompanha estados, permite atualizações seletivas, preserva conteúdo escrito manualmente e oferece recuperação após interrupções. Avalio o agente com testes de regressão e experimentos estruturados de precisão, cobertura e consistência entre idiomas. A ampliação da cobertura e as metas de qualidade continuam em evolução, sem serem apresentadas como resultados já alcançados. O projeto utiliza inferência local, não ajuste dos pesos do modelo.

**Tecnologias:** Ruby · Ruby on Rails · Next.js · TypeScript · PostgreSQL · Docker · Ollama · Python · Markdown

### [Payment Reconciliation Lab](https://github.com/juniocr26/payment-reconciliation-lab)

Projeto de portfólio backend em evolução, redirecionado de uma aplicação anterior de comércio. O fluxo de conciliação planejado irá comparar registros locais de pagamentos com pagamentos de teste do Stripe, distinguir divergências de falhas de APIs externas e permitir inspecionar regras de comparação, execuções repetidas e evidências de auditoria em uma interface Angular. O fluxo de conciliação ainda está em desenvolvimento.

**Tecnologias:** Java · Spring Boot · Spring Security · Spring Data JPA · Hibernate · Angular · TypeScript · PostgreSQL · Flyway · Stripe · Maven · JUnit · Mockito · Testcontainers · Vitest · Docker

### VivaBem

Plataforma independente de atendimento psicológico em desenvolvimento. Seu ecossistema utiliza Laravel, Node.js, APIs REST, mensageria assíncrona, agendamentos, integrações de pagamento, notificações e comunicação em tempo real. Também desenvolvo ferramentas técnicas internas para inspeção de infraestrutura, bancos de dados, filas e logs da aplicação. A plataforma inclui uma PWA e um aplicativo Android com Trusted Web Activity. O repositório é privado; por isso, a descrição permanece em nível geral.

**Tecnologias:** PHP · Laravel · Node.js · Alpine.js · Tailwind CSS · RabbitMQ · Redis · MySQL · MongoDB · Stripe Connect · Mercado Pago · WebSockets · Docker · PWA · TWA · Bubblewrap

### [URL Shortener](https://github.com/juniocr26/url-shortener)

API de encurtamento de URLs concluída em Python, com criação autenticada de links e redirecionamentos públicos. Utiliza alocação atômica de identificadores no Redis, codificação Base62, ofuscação reversível de códigos com largura fixa e persistência no Cassandra. Inclui validação de entradas, tratamento de falhas de infraestrutura, testes automatizados e configuração local com três nós Cassandra.

**Tecnologias:** Python · FastAPI · Pydantic · Redis · Cassandra · Pytest · Docker Compose

### [ENV Auditor](https://github.com/juniocr26/env-auditor)

CLI concluída em Python, sem dependências externas, para conferir chaves de arquivos de ambiente com base em exemplos de referência. Preserva valores existentes, oferece modos de auditoria e simulação e cria backups privados antes de substituições atômicas. Inclui interpretação de atribuições, proteções contra links simbólicos e testes de idempotência e falhas. Não realiza análise semântica de uso de variáveis no código nem detecção de segredos.

**Tecnologias:** Python · argparse · pathlib · unittest

### [Go Image Optimizer](https://github.com/juniocr26/go-image-optimizer)

Aplicação concluída de processamento de imagens com serviço HTTP em Go e interface Next.js. Oferece compressão, redimensionamento, conversão de formatos e pré-visualizações compatíveis com o navegador. O backend detecta formatos pelo conteúdo, aplica limites de upload e pixels, trata orientação EXIF, utiliza codecs específicos, retorna erros explícitos e realiza desligamento controlado. O comportamento HTTP e o processamento de imagens contam com testes automatizados.

**Tecnologias:** Go · net/http · WebP · AVIF · libheif · Next.js · React · TypeScript · Tailwind CSS · Docker
